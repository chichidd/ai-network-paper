\section{Problem Statement}
\label{sec:problem}

We formalize post-training detector integration, define the ordered selection
objective, and derive its selection and privacy guarantees.

\subsection{System Model}

After local detector fitting has ended, $J$ clients expose a pool of $M$
candidate detectors. Our experiments assign one candidate to each client,
while the method allows $J$ and $M$ to vary independently. For candidate
$i$, let $p_i(x)\in\mathbb R^{h_i}$ denote its native probability output.
Because different candidates may use different native label coordinates, the
method validates a hard semantic map
\begin{equation}
A_i\in\{0,1\}^{(C+1)\times h_i},
\qquad
\mathbf 1^\top A_i=\mathbf 1^\top,
\end{equation}
and forms
\begin{equation}
q_i(x)=A_i p_i(x)\in\Delta^{C},
\label{eq:aligned_output}
\end{equation}
where $\Delta^C$ is the probability simplex with $C+1$ coordinates. The
first $C$ coordinates follow a frozen target ontology, whereas the last
coordinate, denoted by $\bot$, collects unsupported outputs. Thus, any mass
assigned to $\bot$ remains visible to every later Brier calculation.

Before selection begins, the method freezes every candidate, semantic map,
and source-side class count. It also assigns disjoint record partitions to
candidate fitting, selection calibration, stacker fitting, and sealed testing.
Because test labels remain unopened until both the selected set and stacker
have been frozen, they cannot affect calibration, cost, or selection.

The selection stage uses a logical cost for each selected candidate. Let
$K_i$ be candidate $i$'s serialized size, let $B_t$ be the number of
stacker-fit records, and let $d$ be the logical byte width of one probability
element. For a selected set $S$, define
\begin{equation}
C_{\mathrm{sel}}(S)=\sum_{i\in S}b_i,
\qquad
b_i=J K_i+dB_t(C+1).
\label{eq:candidate_cost}
\end{equation}
The first term delivers a selected candidate to $J$ clients, and the second
uploads one aligned probability block per stacker-fit record. Given a budget
fraction $\beta$, we set
\begin{equation}
B=\left\lfloor\beta\sum_{i=1}^{M}b_i\right\rfloor.
\label{eq:logical_budget}
\end{equation}
The denominator contains every candidate, including those that may later fail
calibration. The total logical communication measured in the evaluation also
includes the initial candidate upload and the stacker label upload:
\begin{equation}
C_{\mathrm{total}}(S)=\sum_{i=1}^{M}K_i+C_{\mathrm{sel}}(S)+dB_t.
\label{eq:total_logical_communication}
\end{equation}
We use $C_{\mathrm{sel}}$ to enforce the budget and $C_{\mathrm{total}}$ to
compare the complete communication of selected and full pool configurations.

\subsection{Detector Selection Objective}

With the aligned detector pool and logical budget defined, we next specify
what the selector should optimize.

If the coordinator ranks candidates only by average current utility, it may
omit the sole contributor that supports an important class. Source-side
support alone has the opposite weakness: it can retain candidates whose
current probabilities are weak or redundant. A scalar tradeoff can exchange a
positive coverage loss for enough secondary gain, so the method gives weighted
source-side coverage strict priority and compares current behavior only after
that primary value has been fixed.

Accordingly, the intended target is
\begin{equation}
\operatorname{lexmax}_{\varnothing\ne S\subseteq\widehat{\mathcal R}}
\left(C_{\mathrm{sem}}(S),\Phi(S)\right)
\quad\text{s.t.}\quad
\sum_{i\in S}b_i\le B.
\label{eq:lexicographic_target}
\end{equation}
Here, $\widehat{\mathcal R}$ contains candidates that pass calibration,
$C_{\mathrm{sem}}$ measures their weighted source support, and $\Phi$
summarizes current predictive evidence. The following sections define each
quantity. Equation~\ref{eq:lexicographic_target} specifies the decision order.
The primary solver computes its first coordinate exactly and refines the
secondary coordinate heuristically. Only the optional small-pool exhaustive
solver computes the complete lexicographic optimum.

\subsection{Execution and Analysis Model}
\label{sec:information_boundary}

We next specify the execution model and privacy setting used by the analysis.

We evaluate the workflow in a centralized simulation.
Figure~\ref{fig:workflow} encodes the protocol's logical
data dependencies. In a client-side realization, each client perturbs its
selected probability blocks with fresh private Laplace randomness before
upload. The optional sensitivity mode samples the same distribution centrally
to measure utility.

The privacy analysis uses public labels and protects the randomized score
blocks used to fit the stacker. It assumes immutable candidate detectors,
structurally validated semantic maps, honest source-support reports, and fresh
client-side randomness. These assumptions define the cooperative-client
execution model analyzed below.

\label{sec:approach}

In this section, we describe how \Fname calibrates the frozen candidate pool,
selects a budget-feasible detector set, and trains one shared stacker.

\subsection{Selection and Stacking Workflow}

Figure~\ref{fig:workflow} separates the records used for detector selection
from those used for stacker fitting. Calibration outputs determine eligibility
and the selected set, whereas stacker-fit features and score blocks do not
enter selection. Clients use them only after that set has been frozen and then
upload only the selected aligned blocks, optionally perturbed, and their
labels; no contributed detector is updated.

With these stages in place, Algorithm~\ref{alg:silostitch} summarizes the
complete client--server procedure, while the following subsections define
\textsc{Calibrate}, \textsc{Cover}, and \textsc{Refine} in detail. Here,
$\epsilon_b$ is the privacy parameter assigned to one selected detector block;
$\epsilon_b=\infty$ disables perturbation, so $\operatorname{Lap}(0,0)$ denotes
zero noise.

\begin{algorithm}[t]
\caption{\Fname Client--Server Procedure}
\label{alg:silostitch}
\small
\begin{algorithmic}[1]
\Require $\{f_i,A_i,H_i,K_i\}_{i=1}^{M}$, $\mathcal D^{\rm cal}$,
$\{\mathcal D_j^{\rm stk}\}_{j=1}^{J}$, $B$, $\epsilon_b\in(0,\infty]$
\Ensure $\widehat S$, $\widehat f$
\State Clients $\to$ Server: $\{f_i,A_i,H_i,K_i\}_{i=1}^{M}$
\State $(\widehat{\mathcal R},\Gamma,w,b,\Phi)\gets
\Call{Calibrate}{\mathcal D^{\rm cal}}$
\State $(W^\star,S_0)\gets\Call{Cover}{\widehat{\mathcal R},\Gamma,w,b,B}$
\State $\widehat S\gets\Call{Refine}{S_0,W^\star,\Phi,B}$
\State Server $\to$ Clients: $\{f_i,A_i\}_{i\in\widehat S}$
\For{$j=1,\ldots,J$ \textbf{in parallel}}
    \State $Z_j\gets\operatorname{concat}_{i\in\widehat S}q_i(X_j^{\rm stk})$
    \State $(\Xi_j)_{t,i,k}\overset{\mathrm{iid}}{\sim}
    \operatorname{Lap}(0,2/\epsilon_b)$
    \State $\widetilde Z_j\gets Z_j+\Xi_j$
    \State Client $j\to$ Server: $(\widetilde Z_j,Y_j^{\rm stk})$
\EndFor
\State $\widehat f\gets\Call{Fit}{\bigcup_j(\widetilde Z_j,Y_j^{\rm stk})}$
\State \Return $(\widehat S,\widehat f)$
\end{algorithmic}
\end{algorithm}

\subsection{Probability Alignment and Brier Calibration}

Following the workflow overview, we first specify how aligned outputs are
calibrated and summarized.

For calibration record $(x_t,y_t)$, let $e_{y_t}\in\mathbb R^{C+1}$ be the
one-hot label vector with a zero $\bot$ coordinate. We evaluate each candidate
with the complete aligned output and define
\begin{equation}
\ell_{i,t}=\frac12\left\|q_i(x_t)-e_{y_t}\right\|_2^2,
\qquad
g_{i,t}=1-\ell_{i,t}\in[0,1].
\label{eq:brier_utility}
\end{equation}
Thus, $g_{i,t}$ is one full-vector Brier utility rather than a collection of
coordinate-wise scores.

\bheading{Eligibility screening} To screen out candidates whose average
current loss is either too large or too
uncertain, the method uses $N$ calibration records and failure level
$\delta\in(0,1)$ to compute
\begin{equation}
\widehat\mu_i=\frac1N\sum_{t=1}^{N}g_{i,t},
\qquad
r=\sqrt{\frac{\log(4M/\delta)}{2N}},
\label{eq:overall_calibration}
\end{equation}
and admits candidate $i$ only if
\begin{equation}
R_i^+=1-\widehat\mu_i+r\le\tau_L.
\label{eq:risk_gate}
\end{equation}
Accordingly, the calibration-eligible pool is
\begin{equation}
\widehat{\mathcal R}=\{i:R_i^+\le\tau_L\}.
\label{eq:eligible_pool}
\end{equation}
Thus, eligibility depends on an upper confidence bound on risk rather than on
empirical utility alone.

\bheading{Classwise evidence} Average eligibility does not preserve
class-specific evidence for later
refinement and certification. For class $c$, let
$N_c=\sum_t\mathbf 1\{y_t=c\}$ and
\begin{equation}
\widehat\mu_{i,c}=\frac1{N_c}\sum_{t:y_t=c}g_{i,t}.
\end{equation}
Because the protocol requires every calibration class to occur, $N_c>0$.
The class-conditional radius and lower utility are
\begin{equation}
r_c=\sqrt{\frac{\log(4MC/\delta)}{2N_c}},
\qquad
a_{i,c}=\left[\widehat\mu_{i,c}-r_c\right]_+,
\label{eq:class_lower_utility}
\end{equation}
where $[z]_+=\max\{0,z\}$.
Hence, $a_{i,c}$ is the class-specific lower score used by the secondary
objective and the effective-coverage certificate.

\bheading{Behavioral similarity} Two eligible candidates can still behave
almost identically. To measure this
redundancy, the method deterministically selects a class-stratified anchor set
$\mathcal A$ and forms
\begin{equation}
z_i=\operatorname{vec}\left([q_i(x_t)]_{t\in\mathcal A}\right),
\qquad
\kappa_{i,k}=\left[
\frac{\langle z_i,z_k\rangle}{\|z_i\|_2\|z_k\|_2}
\right]_{0}^{1}.
\label{eq:behavior_similarity}
\end{equation}
Here, $[\cdot]_0^1$ clips numerical roundoff into $[0,1]$. We use
$\kappa_{i,k}$ in a facility-location term that measures representativeness,
not as a pairwise-diversity score.

\subsection{Coverage-Prioritized Detector Selection}

Calibration now supplies the evidence needed for budgeted selection. We first
define the primary support objective.

\bheading{Weighted semantic coverage} For candidate $i$ and target class $c$,
let $H_{i,c}$ be the accepted
source-side support count after semantic mapping. After fixing
$n_{\min}>0$, define
\begin{equation}
\Gamma_{i,c}=\mathbf 1\{H_{i,c}\ge n_{\min}\}.
\label{eq:semantic_presence}
\end{equation}
If $H_c=\sum_i H_{i,c}>0$, we define
\begin{equation}
w_c=\frac{H_c^{-1/2}}{\sum_{d=1}^{C}H_d^{-1/2}},
\qquad
\sum_{c=1}^{C}w_c=1.
\label{eq:semantic_weights}
\end{equation}
Thus, classes with less aggregate source support receive greater weight.
Then, for any selected set $S$,
\begin{equation}
C_{\mathrm{sem}}(S)=
\sum_{c=1}^{C}w_c
\mathbf 1\{\exists i\in S:\Gamma_{i,c}=1\}.
\label{eq:semantic_coverage}
\end{equation}
The $\bot$ coordinate never contributes to this coverage. Consequently,
$C_{\mathrm{sem}}$ measures the breadth of declared source support rather than
current predictive accuracy.

\bheading{Secondary behavioral objective} Only after fixing semantic coverage
does the method compare current
predictive behavior. With $h_\tau(z)=1-e^{-z/\tau}$, define
\begin{align}
U(S)
&=\frac1N\sum_{t=1}^{N}
h_{\tau_U}\!\left(\sum_{i\in S}g_{i,t}\right),
\nonumber\\
C_{\mathrm{pred}}(S)
&=\frac1C\sum_{c=1}^{C}
h_{\tau_C}\!\left(\sum_{i\in S}a_{i,c}\right),
\nonumber\\
D_{\mathrm{rep}}(S)
&=\frac1{|\widehat{\mathcal R}|}
\sum_{k\in\widehat{\mathcal R}}
\max_{i\in S}\kappa_{i,k}.
\label{eq:secondary_components}
\end{align}
Here, $U$ summarizes record-level utility, $C_{\mathrm{pred}}$ summarizes
conservative classwise evidence, and $D_{\mathrm{rep}}$ rewards behavior that
represents the eligible pool.
Here and throughout the analysis, we set
$\max_{i\in\varnothing}\kappa_{i,k}=0$.
Unlike $C_{\mathrm{sem}}$, $C_{\mathrm{pred}}$ averages classes uniformly.
After fixing nonnegative weights that sum
to one, the secondary objective is
\begin{equation}
\Phi(S)=\lambda_U U(S)+\lambda_C C_{\mathrm{pred}}(S)
+\lambda_D D_{\mathrm{rep}}(S).
\label{eq:secondary_objective}
\end{equation}
This score is used only after semantic coverage has been fixed.

\bheading{Budgeted selection procedure} We therefore define the feasible
family and its optimal primary value as
\begin{equation}
\begin{aligned}
\mathcal F_B&=\left\{
\varnothing\ne S\subseteq\widehat{\mathcal R}:
\sum_{i\in S}b_i\le B
\right\},\\
W^\star&=\max_{S\in\mathcal F_B}C_{\mathrm{sem}}(S).
\end{aligned}
\label{eq:primary_value}
\end{equation}
To compute $W^\star$, the primary solver encodes every $\Gamma_i$ as a
$C$-bit mask and uses a sparse dynamic program to recover a least-cost witness.
It then spends any remaining budget through density-based fill and accepts a
one-for-one replacement only when the change preserves $W^\star$ and improves
$\Phi$ by more than the fixed tolerance $\varepsilon_{\mathrm{loc}}$.

For a matched comparison, we also apply the same
fill--one-swap procedure without semantic priority. If that no-semantic
result already attains $W^\star$, \Fname returns the same set unchanged.
Otherwise, it refines the exact coverage witness and, when available, a
coverage-optimal singleton seed, then returns the better locally refined
result. Thus, when the semantic constraint is inactive, both variants return
the same set; they differ only when semantic priority changes the refinement
path.

\subsection{Shared Stacker Learning}

After the selector fixes $\widehat S$, the selected representation is
\begin{equation}
\phi_{\widehat S}(x)=
\operatorname{concat}_{i\in\widehat S}q_i(x)
\in\mathbb R^{|\widehat S|(C+1)}.
\label{eq:selected_representation}
\end{equation}

\bheading{Local score perturbation} When local score protection is enabled,
client $j$ independently perturbs
every coordinate of each selected block:
\begin{equation}
\widetilde q_i(x_t)=q_i(x_t)+\eta_{i,t},
\qquad
\eta_{i,t,k}\overset{\mathrm{iid}}{\sim}
\operatorname{Lap}\!\left(0,\frac{2}{\epsilon_b}\right).
\label{eq:local_laplace_release}
\end{equation}
We write the perturbed representation as
\begin{equation}
\widetilde\phi_{\widehat S}(x)=
\operatorname{concat}_{i\in\widehat S}\widetilde q_i(x).
\label{eq:private_selected_representation}
\end{equation}

\bheading{Shared stacker fitting} Using the independent stacker-fit partition
$\mathcal D^{\mathrm{stk}}$, the
coordinator then trains
\begin{equation}
\widehat f_{\widehat S}=\mathsf{Fit}_{\mathrm{global}}
\left(
\{(\widetilde\phi_{\widehat S}(x_t),y_t):
(x_t,y_t)\in\mathcal D^{\mathrm{stk}}\}
\right).
\label{eq:shared_stacker}
\end{equation}
For the nonprivate configuration, the method sets
$\widetilde\phi_{\widehat S}=\phi_{\widehat S}$. Both configurations use only
the columns indexed by $\widehat S$. Unselected blocks therefore cannot affect
the learned classifier.

The centralized sensitivity experiment samples
Eq.~\ref{eq:local_laplace_release} after selection to measure the effect of
noise. A distributed realization samples the same noise privately at each
client. At sealed-test inference, the method uses the same selected layout and
leaves every contributed detector unchanged.

\section{Theoretical Analysis}
\label{sec:method_analysis}

In this section, we establish guarantees for score-upload privacy,
calibration, primary optimization, and local secondary refinement. We then
analyze how client-mixture shift affects the interpretation of current
evidence.

\subsection{Local Privacy of Score Uploads}

We first analyze the privacy of the score blocks randomized before upload.

We fix the selected set before observing any stacker-fit record and treat each
record label as public. Accordingly, $(x,y)$ and $(x',y)$ are adjacent only
when their feature vectors differ. This label-fixed relation is necessary
because Algorithm~\ref{alg:silostitch} uploads $y$ without perturbation. For a
batched upload, adjacent batches have the same size, row alignment, and label
sequence, and they differ in exactly one feature vector. Each client samples
noise independently across records, selected detector blocks, and output
coordinates.

\begin{theorem}[Label-conditional local score privacy]
\label{thm:local_score_privacy}
Suppose that the selected detectors and their semantic maps are fixed and
that $0<\epsilon_b<\infty$ and each client uses fresh private randomness in
Eq.~\ref{eq:local_laplace_release}. Then one released detector block is
$(\epsilon_b,0)$-locally differentially private under the preceding
adjacency relation. If $s=|\widehat S|$ blocks are released for the same
record, their joint release is $(s\epsilon_b,0)$-locally differentially
private. Under one-record replacement, releasing the entire client batch has
the same record-level guarantee. More generally, assigning parameter
$\epsilon_i$ to block $i$ gives
$(\sum_{i\in\widehat S}\epsilon_i,0)$-local differential privacy.
\end{theorem}

\begin{proof}
Because $q_i(x)$ and $q_i(x')$ are probability vectors,
$\lVert q_i(x)-q_i(x')\rVert_1\le2$. Therefore, coordinatewise Laplace noise
with scale $2/\epsilon_b$ bounds the density ratio of one released block by
$e^{\epsilon_b}$. Sequential composition over the $s$ selected blocks gives
$e^{s\epsilon_b}$. Because different rows use independent randomization and
neighboring batches differ in one row, parallel composition across rows leaves
this bound unchanged. Appending the unchanged public labels does not alter the
density ratio.
\end{proof}

Thus, a total per-record score budget $\epsilon$ can be obtained by assigning
$\epsilon_b=\epsilon/s$ to each block, which changes the noise scale to
$2s/\epsilon$. This is a label-conditional, record-level guarantee for the
randomized score upload. Repeated uploads compose across rounds.

\subsection{Calibration under Heterogeneous Clients}

The privacy result concerns the fit partition, whereas detector eligibility
depends on separate calibration records. We therefore analyze those
statistics next.

Because calibration records can originate from different clients and
classes, we condition on both the observed client--label design
$\mathcal I=\{(j_t,y_t)\}_{t=1}^{N}$ and the candidate pool $\mathcal Q$
frozen by the preceding fit stage. We assume that calibration records are
conditionally independent given $(\mathcal Q,\mathcal I)$, although their
conditional distributions may differ across $t$. Define
\begin{equation}
\mu_i=\frac1N\sum_{t=1}^{N}\mathbb E[g_{i,t}\mid\mathcal Q,\mathcal I],
\qquad
R_i=1-\mu_i,
\label{eq:heterogeneous_overall_mean}
\end{equation}
and
\begin{equation}
\mu_{i,c}=\frac1{N_c}\sum_{t:y_t=c}
\mathbb E[g_{i,t}\mid\mathcal Q,\mathcal I].
\label{eq:heterogeneous_class_mean}
\end{equation}
Thus, these quantities describe the record-weighted calibration mixture
rather than equal-client or worst-client performance.

\begin{theorem}[Simultaneous calibration]
\label{thm:simultaneous_calibration}
Under the preceding assumptions, with probability at least $1-\delta$, the
following inequalities hold simultaneously for every candidate $i$ and
class $c$:
\begin{align}
R_i&\le R_i^+\le R_i+2r,
\label{eq:simultaneous_risk}\\
\max\{0,\mu_{i,c}-2r_c\}
&\le a_{i,c}\le\mu_{i,c}.
\label{eq:simultaneous_class}
\end{align}
Consequently, the inequalities remain valid for every candidate in any set
selected adaptively from the calibration statistics.
\end{theorem}

\begin{proof}
Conditioning on $(\mathcal Q,\mathcal I)$, Hoeffding's inequality gives
\[
\Pr\{|\widehat\mu_i-\mu_i|>r\mid\mathcal Q,\mathcal I\}
\le2e^{-2Nr^2}=\frac{\delta}{2M}.
\]
Therefore, a union bound over $M$ candidates spends at most $\delta/2$.
Likewise,
\[
\Pr\{|\widehat\mu_{i,c}-\mu_{i,c}|>r_c\mid\mathcal Q,\mathcal I\}
\le2e^{-2N_cr_c^2}=\frac{\delta}{2MC},
\]
so a second union bound over $MC$ pairs spends at most $\delta/2$. The
intersection has probability at least $1-\delta$, and it does not require
different candidates evaluated on the same record to be independent.

On this event, $1-\widehat\mu_i+r$ lies between $R_i$ and $R_i+2r$.
Moreover, $\widehat\mu_{i,c}-r_c$ lies between $\mu_{i,c}-2r_c$ and
$\mu_{i,c}$. Applying $[\cdot]_+$ proves the class inequalities. Because
the event covers all $M+MC$ coordinates before selection, taking a
data-dependent subset requires no additional union bound over $2^M$ sets.
\end{proof}

For any pool $\mathcal E$, let $W(\mathcal E)$ be the largest feasible
semantic coverage available from that pool, with value zero if no nonempty
set is feasible. On the event in Theorem~\ref{thm:simultaneous_calibration},
define
\begin{equation}
\mathcal R^-=\{i:R_i\le\tau_L-2r\},
\qquad
\mathcal R^0=\{i:R_i\le\tau_L\}.
\end{equation}
Then,
\begin{equation}
\mathcal R^-\subseteq\widehat{\mathcal R}\subseteq\mathcal R^0,
\qquad
W(\mathcal R^-)\le W(\widehat{\mathcal R})\le W(\mathcal R^0).
\label{eq:coverage_sandwich}
\end{equation}
Indeed, the left inclusion follows from $R_i^+\le R_i+2r$, while the right
inclusion follows from $R_i\le R_i^+$. Thus, if one primary-optimal witness
over $\mathcal R^0$ lies entirely in $\mathcal R^-$, calibration preserves
the population-mixture primary value.

With $\tau_L=1$, the upper-confidence gate acts as a
finite-sample admissibility screen over normalized Brier risk. We therefore
refer to $\widehat{\mathcal R}$ as the calibration-eligible pool.

\subsection{Exact Primary Coverage under a Hard Budget}

The simultaneous event validates the statistics used to form the eligible
pool. With that pool fixed, we now characterize the primary selection problem
and its exact solver.

\begin{theorem}[Primary hardness and exact parameterized solver]
\label{thm:primary_solver}
Computing $W^\star$ is NP-hard, even when every candidate is eligible, every
cost is one, and all class weights are uniform. Nevertheless, the bitmask
dynamic program returns a
nonempty feasible set $S_0$ with
\begin{equation}
C_{\mathrm{sem}}(S_0)=W^\star.
\end{equation}
It stores at most $2^C$ masks and examines at most
$|\widehat{\mathcal R}|2^C$ state transitions. Thus, its primary stage is
fixed-parameter tractable in $C$.
\end{theorem}

\begin{proof}
For hardness, take a Maximum Coverage instance with universe
$\{1,\ldots,C\}$, subsets $\Gamma_1,\ldots,\Gamma_M$, and cardinality
limit $k$. Set $b_i=1$, $B=k$, and $w_c=1/C$. Maximizing
$C_{\mathrm{sem}}$ then solves that instance up to the constant factor
$1/C$.

For exactness, after processing the first $t$ eligible candidates, associate
each reachable union mask $h$ with its least-cost witness. Omitting candidate
$t$ preserves an earlier state, whereas including it extends an earlier
mask to $h\vee\Gamma_t$. Every subset makes exactly one of these choices.
Moreover, a lower-cost witness for the same mask dominates every higher-cost
witness under all future union operations. Induction therefore shows that
the final table contains the least-cost witness for every reachable mask.
Scanning the budget-feasible masks returns exactly $W^\star$.

A $C$-bit mask has at most $2^C$ values, and each eligible candidate extends
each current mask at most once. When all attainable masks have value zero,
the solver returns the least-cost feasible singleton, which enforces
the nonempty stacker input without changing the primary value.
\end{proof}

The transition bound excludes witness reconstruction and sorting overhead.
We restrict the evaluated solver to at most $10^6$ states. The exactness
guarantee applies to every instance processed within this limit.

\subsection{Secondary Objective and Local Refinement}

The primary solver determines $W^\star$. The remaining question is how the
method compares feasible sets that attain this value.

Let $\mathcal V=\{C_{\mathrm{sem}}(S):S\in\mathcal F_B\}$ contain the
attainable primary values. When $\mathcal V$ has at least two values, let
$\Delta_{\mathrm{inst}}$ be its smallest positive gap. Because
$0\le\Phi(S)\le1$, any coefficient $K>1/\Delta_{\mathrm{inst}}$ is sufficient
to make every maximizer of $KC_{\mathrm{sem}}+\Phi$ lexicographic for that
fixed instance. Normalized class weights can make the smallest positive
coverage gap arbitrarily small, so a universal finite coefficient is
unavailable. The strict order in
Eq.~\ref{eq:lexicographic_target} does not require instance-specific scale
tuning.

\begin{proposition}[Secondary structure]
\label{prop:secondary_structure}
For fixed calibration statistics, $U$, $C_{\mathrm{pred}}$, and
$D_{\mathrm{rep}}$ are normalized, monotone, submodular set functions.
Consequently, their nonnegative weighted combination $\Phi$ has the same
properties.
\end{proposition}

\begin{proof}
For $U$ and $C_{\mathrm{pred}}$, each summand applies the nondecreasing
concave function $h_\tau$ to a nonnegative modular sum. Therefore, the gain
from adding the same candidate cannot increase as the current set grows. For
$D_{\mathrm{rep}}$, target $k$ contributes
$\max_{i\in S}\kappa_{i,k}$, whose marginal gain is
\[
\max\{0,\kappa_{a,k}-\max_{i\in S}\kappa_{i,k}\}.
\]
This gain also cannot increase as $S$ grows. Averaging and taking a
nonnegative weighted sum preserve all three properties.
\end{proof}

Although $\Phi$ is monotone submodular, the equal-primary family
\begin{equation}
\mathcal F^\star=
\{S\in\mathcal F_B:C_{\mathrm{sem}}(S)=W^\star\}
\end{equation}
is not downward closed and need not satisfy an exchange axiom. Therefore,
standard monotone-submodular knapsack guarantees, including $1-1/e$, do not
apply to the secondary refinement stage.

For $S\in\mathcal F^\star$, let $\mathcal N_1(S)$ contain every set obtained
by removing exactly one selected candidate and adding exactly one unselected
candidate while preserving budget feasibility and $W^\star$.

\begin{theorem}[Coverage preservation and one-swap certificate]
\label{thm:local_refinement}
Given an exact primary solution, the refinement procedure
terminates after finitely many accepted operations and returns
$\widehat S\in\mathcal F^\star$ such that
\begin{equation}
\Phi(S')\le\Phi(\widehat S)+\varepsilon_{\mathrm{loc}},
\qquad
\forall S'\in\mathcal N_1(\widehat S).
\label{eq:one_swap_certificate}
\end{equation}
\end{theorem}

\begin{proof}
The constrained seed has coverage $W^\star$. Because
$C_{\mathrm{sem}}$ is monotone and $W^\star$ is already maximal, every
feasible fill keeps that value. The algorithm checks every
accepted replacement for budget feasibility and equality to $W^\star$.
Each accepted operation also increases $\Phi$ by more than
$\varepsilon_{\mathrm{loc}}$. Because the candidate pool has only finitely
many subsets, the procedure terminates. At termination, the exhaustive
one-for-one search has found no feasible coverage-preserving replacement
whose gain exceeds the tolerance, which proves
Eq.~\ref{eq:one_swap_certificate}.
\end{proof}

The certificate covers the one-swap neighborhood explored by the refinement
procedure. The fill stage ranks candidates
by gain per byte and stops when the chosen candidate's absolute gain falls
below tolerance; broader additions and multi-candidate exchanges remain
separate optimization choices.

\subsection{Effective Coverage under Client Mixture Shift}

The preceding results treat declared support and current predictive behavior
as separate quantities. We now ask when the former is backed by the latter
and how that relation changes under client-mixture shift.

We use the following quantities as post-selection certificates for the frozen
returned set, reusing statistics already computed during calibration.

To test whether declared source support is backed by current evidence, let
$\vartheta_c\in[0,1]$ be a prespecified current-competence threshold and define
\begin{equation}
C_{\mathrm{cert}}(S;\boldsymbol\vartheta)=
\sum_{c=1}^{C}w_c
\mathbf 1\{\exists i\in S:
\Gamma_{i,c}=1\ \wedge\ a_{i,c}\ge\vartheta_c\}.
\label{eq:certified_coverage}
\end{equation}
Thus, a class contributes only when a selected detector provides both declared
source support and a conservative current-utility score.
For comparison, let $C_\mu^a(S;\boldsymbol\vartheta)$ replace
$a_{i,c}\ge\vartheta_c$ by
$\mu_{i,c}^a\ge\vartheta_c$, where
$a\in\{\mathrm{cal},\mathrm{dep}\}$.

Let $h=(j,c)$ index a client--class cell. Suppose that detector behavior
within each cell remains stable between calibration and deployment, while
only the mixture weights change. Let $R_{i,h}\in[0,1]$ denote the cell risk,
and let $\pi_h^{\mathrm{cal}}$ and $\pi_h^{\mathrm{dep}}$ denote the two
mixtures. For $a\in\{\mathrm{cal},\mathrm{dep}\}$, define
\begin{equation}
R_i^a=\sum_{j,c}\pi_{j,c}^a R_{i,j,c},
\qquad
\mu_{i,c}^a=\sum_j\pi_{j\mid c}^a(1-R_{i,j,c}),
\label{eq:mixture_quantities}
\end{equation}
and let $\operatorname{TV}(p,q)=\tfrac12\lVert p-q\rVert_1$. Under the
calibration design, the means in
Eqs.~\ref{eq:heterogeneous_overall_mean}--\ref{eq:heterogeneous_class_mean}
equal $1-R_i^{\mathrm{cal}}$ and $\mu_{i,c}^{\mathrm{cal}}$, respectively.

\begin{theorem}[Effective coverage under mixture shift]
\label{thm:post_selection_certificates}
Suppose that the within-class client mixtures differ by at most $\eta_c$.
On the simultaneous calibration event, every adaptively selected set
$\widehat S$ satisfies
\begin{equation}
\begin{aligned}
C_\mu^{\mathrm{cal}}(\widehat S;
\boldsymbol\vartheta+\boldsymbol\eta+2\boldsymbol r)
&\le C_{\mathrm{cert}}(\widehat S;
\boldsymbol\vartheta+\boldsymbol\eta)
\\
&\le C_\mu^{\mathrm{dep}}(\widehat S;\boldsymbol\vartheta)
\le C_{\mathrm{sem}}(\widehat S).
\end{aligned}
\label{eq:certified_coverage_sandwich}
\end{equation}
where $(\boldsymbol r)_c=r_c$ and
$(\boldsymbol\eta)_c=\eta_c$.

Moreover, if
$\operatorname{TV}(\pi^{\mathrm{dep}},\pi^{\mathrm{cal}})\le\eta$, then
\begin{equation}
R_i^{\mathrm{dep}}\le R_i^{\mathrm{cal}}+\eta.
\label{eq:risk_mixture_shift}
\end{equation}
\end{theorem}

\begin{proof}
Theorem~\ref{thm:simultaneous_calibration} and the mixture assumption give
\[
\mu_{i,c}^{\mathrm{cal}}\ge\vartheta_c+\eta_c+2r_c
\Longrightarrow a_{i,c}\ge\vartheta_c+\eta_c
\Longrightarrow\mu_{i,c}^{\mathrm{dep}}\ge\vartheta_c.
\]
Intersecting these implications with the fixed support edge
$\Gamma_{i,c}=1$, taking the existential quantifier over selected
candidates, and summing class weights proves
Eq.~\ref{eq:certified_coverage_sandwich}.

For the final claim, total variation bounds the change in the expectation of
any $[0,1]$-valued function. Applying this bound to the cell risks yields
Eq.~\ref{eq:risk_mixture_shift}.
\end{proof}

Thus, $C_{\mathrm{cert}}$ connects the historical class support of selected
detectors with current class-conditional Brier utility under client-mixture
shift. The executed selector uses $C_{\mathrm{sem}}$ and $\Phi$;
$C_{\mathrm{cert}}$ and the mixture-sensitivity bound are derived analysis
quantities for the frozen returned set.
